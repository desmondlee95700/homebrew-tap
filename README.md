# desmondlee95700/homebrew-tap

Homebrew casks for [AIUsage](https://github.com/desmondlee95700/AIUsage).

```bash
brew tap desmondlee95700/tap
brew trust desmondlee95700/tap   # Homebrew 7+ refuses casks from third-party taps until trusted
brew install --cask aiusage
```

The cask is updated automatically by the AIUsage release workflow; don't edit the version by hand.
